eeaCronPicker

Vue 3 компонент для выбора cron-расписания

Базовый пример

v-model: {{ cron1 }}

Поддержка локализации

v-model: {{ cron2 }}

Кастомная тема (тёмная)

v-model: {{ cron3 }}

Кастомная тема (зелёная)

v-model: {{ cron4 }}

Начальное значение (каждый понедельник в 09:30)

v-model: {{ cron5 }}

Внешний translator (эмуляция vue-i18n)

Передаём функцию :translator="myTranslator" — компонент использует её вместо встроенных локалей.

v-model: {{ cron6 }}
